# product-layer (stub)

Placeholder until `skills/product-layer/` lands (JEB-2030). It only exists so the bench can be smoke-tested with a
skill arm; its results say nothing about the real skill.

Before writing a flow spec:

1. Name the user's goal for each flow and the screen where they have it.
2. Cut every step that does not move the user toward it; prefer defaults and data the product already has over asking.
3. For every screen, decide what it shows when empty, while loading and on error, and how the user gets out.
4. Leave colors, fonts and motion to the visual pass.
